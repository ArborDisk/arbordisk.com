questions

Before you install it.

Have a question that is not here? Write to us.

Can ArborDisk delete my files?

Not on its own. You choose what to remove, and ArborDisk asks you to confirm first. Most actions move items to the Trash. The agent hooks and the MCP server only read. They cannot change files.

Does it send my data anywhere?

No. ArborDisk has no telemetry and needs no account. The license check runs on your computer. A webhook alert goes only to a URL that you set.

What is free and what is Pro?

The scanner, the map, the terminal UI, alerts, hooks and the basic MCP tools are free for all use. Pro adds the tabs that find space you can get back. They cover agent worktrees, containers and VM disks, AI caches, content duplicates, security checks and secrets.

Is Pro a subscription?

No. You pay one time and get 12 months of updates. After that, your version keeps working. Buy another year of updates when you want them.

Do companies pay more?

No. Pro is $39 for each person, at home or at work. Teams get a lower price from 10 seats. A site license covers everyone at one company, build servers included.

Does it work over SSH and on servers?

Yes. Run arbor --tui in any terminal. The map uses 24-bit color. arbor watch and arbor check also run without a desktop.

Which coding agents does it support?

arbor connect adds the hooks and the MCP server to Claude Code and Codex. It adds the MCP server to Claude Desktop and Antigravity. Other MCP clients can run arbor mcp. arbor disconnect removes only what ArborDisk added.
